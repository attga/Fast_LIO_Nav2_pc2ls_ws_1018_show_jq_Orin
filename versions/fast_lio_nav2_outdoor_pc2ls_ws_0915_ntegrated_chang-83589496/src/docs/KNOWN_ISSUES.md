## 当前功能限制

- Manager 只做启动初始化，LOST 后不触发 SC；依赖 ICP 自恢复。施工或大范围地图变化时可能持续拒绝。启动服务/确认失败后锁定错误，需检查日志后重启。
- 共享 Scan Context 的 xy2theta 仍有非 void 函数缺少返回值的编译警告，保留原算法未在整理中修改；退化输入处理需单独检查。
- SC 一致性累计的是连续有效结果，拒绝帧不会清零；对称场景、静止冷启动成功率和错误候选仍需专项测试。
- GPS/GNSS 未融合，GPS 重定位尚未实现；旧 GPS 对齐实验存在数十米尾部误差，实验配置已从正式入口移除。
- Yesense / wheel 与 base_link 采用经确认的单位变换近似，未做安装标定。IMU 噪声、wheel 比例和 ICP/SC 协方差未完成统计标定；不应把当前数值视为传感器规格。
- bag0909 没有 /imu/data_raw，只能验证关闭 Yesense 的配置。Global 融合 Local 输出，两路状态有关联，不能假定独立。
- two_d_mode 假定园区平面；若有坡道，应重新评估，不能只提高滤波频率解决倾斜。
- RViz 在 map 下可能受延迟的 map→odom 影响出现点云显示卡顿；切 odom 只能辅助判断显示问题，不能替代 TF/时间链验收。
- 本移植版 FAST-LIO blind 语义与上游不同；历史建图入口仍有专用参数，没有随定位整理做统一算法修改。
